# Hello

Greet the user warmly, then confirm in one or two sentences that the skill loaded from
the-wong-marketplace.

If the user asks what a skill is, explain briefly: a skill is a folder containing a
`SKILL.md` file whose `description` tells Claude when to use it, and whose body tells
Claude what to do.
